# QX - Extractor Quipux

**QX - Extractor Quipux** es una herramienta de escritorio para Windows que permite extraer, organizar y exportar información documental desde Quipux.

La aplicación automatiza la revisión de bandejas, descarga documentos y anexos, genera reportes Excel y, de forma opcional, puede ejecutar análisis documental local para sugerir grupos de documentos relacionados.

## Descarga

Las versiones oficiales se publican en la sección **Releases** de este repositorio.

Cada versión puede incluir:

- Instalador principal de QX.
- Componente opcional de Inteligencia Documental.
- Manual de usuario correspondiente a la versión publicada.

Para instalar QX, descarga el archivo:

[Descargar instalador](https://github.com/jesuszunap/qx-extractor-quipux/releases/download/v3.0.0/QX-Extractor-Quipux-Setup-3.0.0.exe)

Luego ejecútalo en Windows y sigue los pasos del instalador.
Funciones principales

Extracción desde bandejas de Recibidos, Enviados o Ambos.
Descarga opcional de documentos principales en PDF.
Descarga opcional de anexos.
Exportación a Excel con hojas separadas.
Detección opcional de links en PDFs principales.
Revisión opcional del recorrido documental.
Recuperación ante sesión expirada o sesión abierta en otro equipo.
Configuración local de servidores, áreas y opciones avanzadas.
Inteligencia Documental local opcional para sugerir relaciones entre documentos.

Inteligencia Documental local
Desde la versión 3.0.0, QX incorpora una función opcional de Inteligencia Documental local.
Esta función permite generar hojas adicionales en el Excel para apoyar tareas de clasificación, trazabilidad y archivación documental:

Resumen IA
Grupos sugeridos
Relaciones documentales

La Inteligencia Documental de QX:

funciona localmente en el equipo del usuario;
no usa APIs externas;
no envía documentos a servicios en la nube;
no modifica documentos originales;
no reemplaza el criterio del analista;
genera sugerencias que deben ser revisadas por el usuario.

El componente IA se descarga e instala por separado desde la aplicación.
Hojas que puede generar el Excel
Según las opciones activadas, QX puede generar hojas como:

Recibidos
Enviados
Links detectados
Recorrido documental
Resumen IA
Grupos sugeridos
Relaciones documentales

Las hojas de Inteligencia Documental son opcionales y no agregan columnas nuevas a Recibidos ni Enviados.
Requisitos

Windows.
Mozilla Firefox instalado.
Conexión a internet.
Cuenta válida de Quipux.
Permisos normales de usuario.

QX se instala en el entorno local del usuario y guarda su configuración en AppData.
